# Rotating screensaver art

Four stills made for this theme. Each piece is stored twice:

- `*.txt` is plain Braille art. Omarchy's own screensaver can animate any one of these once it is copied to `~/.config/omarchy/branding/screensaver.txt`. The theme root `screensaver.txt` is `01_golden_halo.txt`.
- `*.ansi.txt` is the same drawing with terminal colors. [omarchy-buddha-screensaver](https://github.com/richfeather-cpu/omarchy-buddha-screensaver) rotates these through ttfx. That player is a separate repository. It reads this folder from `~/.config/omarchy/themes/buddha/screensavers` after the theme is installed.

| Piece | Scene |
| --- | --- |
| `01_golden_halo` | Seated figure, gold halo |
| `02_bodhi_moon` | Figure under the bodhi tree, moon behind |
| `03_enso_stillwater` | Enso ring over still water |
| `04_amber_temple` | Temple gate in amber light |
